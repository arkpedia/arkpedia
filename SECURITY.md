# Security

Report suspected vulnerabilities privately to
[jungermin@arkpedia.net](mailto:jungermin@arkpedia.net). Please include the affected
page or component, impact and minimal reproduction steps. Do not open a public
issue containing exploit details or private account information.

Use synthetic data when reproducing account or import issues. Never send passwords,
login codes, session tokens, private keys or complete game/account exports. If a
credential has been exposed, revoke or rotate it through its provider; deleting a
file or comment does not invalidate the credential.

Security fixes target the current `main` branch and supported live deployment.
Archived branches and tags are retained for reference and are not supported
releases.
