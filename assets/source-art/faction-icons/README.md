# Operator faction emblems

The display-name aliases in `lib/operators/classBranchIcons.ts` resolve the operator dataset to the existing emblem filenames without changing faction membership.

`public/faction-icons/Chiave's Gang.png` is the unmodified game camp logo, retrieved on 2026-09-14 from [ArknightsAssets](https://github.com/ArknightsAssets/ArknightsAssets/blob/c0be4e4428f79c7e87c6889067a6906361ae979b/assets/torappu/dynamicassets/arts/camplogo/logo_chiave.png).

The game supplies the **Rhodes Island** emblem for [Laios's Party](https://github.com/ArknightsAssets/ArknightsAssets/blob/c0be4e4428f79c7e87c6889067a6906361ae979b/assets/torappu/dynamicassets/arts/camplogo/linkage/logo_laios.png) and [Ave Mujica](https://github.com/ArknightsAssets/ArknightsAssets2/blob/41244df3be898a4263ded6367b1b74253f7a2c45/assets/dyn/arts/camplogo/linkage/logo_mujica.png). Those aliases reuse the existing Rhodes Island asset rather than storing duplicate images or inventing a team crest.

These images belong to their respective rights holders; the linked repositories mirror the game assets.
