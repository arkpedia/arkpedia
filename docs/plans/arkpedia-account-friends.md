# Future plan: Arkpedia account friends

Requested 2026-11-05. Planned for later; this is not part of the current Friends tab implementation.

Today, Friends lives at `/account?panel=friends` and supports manual sharing only. A person exports their account and sends the file to a friend, who imports it. Imported profiles are snapshots stored separately from the viewer’s own account; updating one requires another export/import.

The future account-based flow should let Arkpedia users send a friend request from the Find support units page. Requests should appear in the account’s Friends tab, with active requests at the top and the accepted friend list below them. Friends will then be shared through Arkpedia accounts rather than requiring repeated manual file exchange.

Keep the existing manual import/export available while the account-based feature is still planned. Do not show request buttons or a working requests section until that feature is implemented.
